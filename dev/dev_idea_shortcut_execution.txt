idea中相关快捷操作

1.快捷更换属性名及调用处
修改一个对象的属性字段名并自动更新所有调用处:
将鼠标光标放在你需要修改的属性字段名上
- Shift + F6, 在编辑框中输入
- 右键，在弹出的菜单中选择 Refactor（重构） -> Rename...（重命名...）

2.跳转上/下一处代码
在代码浏览的历史记录中前后跳转
ctrl + alt + <- / ctrl + alt + ->
鼠标按键 4/5 (强烈推荐, 如果鼠标有侧边按键 4,5, 可以左手控制键盘 ctrl + 单击 跟进方法调用, 右手操作鼠标控制代码进退, 在idea中阅读代码时极其便捷, 不需要反复移动双手)
